2. Ubuntu

2.1 快捷键：

常用快捷键

快捷键 功能描述
Super 打开活动概览
Super+A 显示所有应用
Super+D 显示桌面（最小化所有窗口）
Alt+Tab 切换窗口
Ctrl+Alt+T 打开终端
Ctrl+Shift+T 终端新建标签页
Ctrl+Alt+L 锁定屏幕

文件/目录操作

命令 功能描述 示例
pwd 显示当前工作目录路径 pwd → /home/yourname/Documents
ls 列出目录内容 ls -l（详细列表）、ls -a（显示隐藏文件）
cd 切换目录 cd /home（绝对路径）、cd ../（上一级目录）
mkdir 创建目录 mkdir test（单个目录）、mkdir -p a/b/c（递归创建）
touch 创建空文件 touch file.txt
cp 复制文件/目录 cp file.txt /tmp/（复制文件）、cp -r dir/ /tmp/（复制目录）
mv 移动/重命名文件/目录 mv file.txt newname.txt（重命名）、mv file.txt /tmp/（移动）
rm 删除文件/目录（谨慎使用！） rm file.txt（删除文件）、rm -r dir/（删除目录）、rm -f file.txt（强制删除）

文件内容查看

命令 功能描述 示例
cat 查看文件全部内容 cat /etc/hosts
less 分页查看长文件（按 q 退出） less /var/log/syslog
head/tail 查看文件开头/结尾内容 head -n 5 file.txt（前 5 行）、tail -f /var/log/auth.log（实时跟踪日志）
grep 搜索文件内容（支持正则表达式） grep "error" /var/log/syslog（查找含“error”的行）

系统信息查看

命令 功能描述 示例
uname -a 查看系统内核信息 uname -a → Linux ubuntu 5.15.0-78-generic ...
df -h 查看磁盘空间使用情况（人类可读格式） df -h → /dev/sda2 100G 30G 65G 32% /
free -h 查看内存使用情况 free -h → Mem: 7.7Gi 2.3Gi 4.1Gi 1.3Gi 0.0Ki 0.0Ki
