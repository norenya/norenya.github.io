1. Redis

  • 官方网站：[Redis 下载](Downloads | Redis)；
选择Redis Open Source，需注册Redis账号（可通用Github账号）；
  • 安装/代码教程：Redis 菜鸟教程/【GeekHour】一小时Redis教程;
先看GeekHour的理论教程，在看菜鸟教程安装；
  • GUI软件：Redis Insight ( github ) /官方网站（下载速度极慢）;
GUI软件还有个RedisDesktopManager，但已4年未更新；

SUM：

  1. 今天在Win11与Ubuntu24上均进行了部署，但Ubuntu官方软件商店中下载Redis Insight速度极慢；
  2. Redis由各类键值驱动，在内存中进行操作，持续性需手动设置，比较接近数组，但纯语法方面并不难，只是作者的语法定义不像同一个人写出来的，会出现DEL与REM都指向“删除”的这种情况；

2. Docker

  • 官方网站：Docker Desktop；
选择 Windows 版本，点击 Download for Windows；
* 下载前需打开BIOS虚拟化
  1. 按下 Ctrl + Shift + Esc 打开任务管理器
  2. 切换到 性能 选项卡
  3. 查看右下角 虚拟化 是否为 已启用
  • 使用教程：【GeekHour】30分钟Docker入门教程;
  • Docker Hub（官方镜像下载点）：Docker Hub ;
